## 💻 Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/ShanuPrajapati12005/Portfolio.git
   cd Portfolio
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start the development server**
   ```bash
   npm run dev
   ```
