# SHANU Portfolio 🚀

[![Live Demo](https://img.shields.io/badge/Live_Demo-shanu--portfolio--dev.vercel.app-10B981?style=for-the-badge&logo=vercel)](https://shanu-portfolio-dev.vercel.app/)

> A premium, interactive, and highly optimized developer portfolio built with React, Vite, and modern animation libraries to showcase full-stack engineering skills, projects, and professional background.

![Portfolio Preview](./public/projects/syncora.png)

## ✨ Features
- **Premium UI/UX:** Designed with a sophisticated "Obsidian & Gold" dark theme, utilizing glassmorphism and subtle gradients.
- **Dynamic Animations:** Smooth scroll reveals, hover effects, and micro-interactions powered by Framer Motion and GSAP.
- **Performance Optimized:** Lightning-fast load times leveraging Vite and optimized asset delivery.
- **Fully Responsive:** Seamlessly adapts from large desktop screens to mobile devices.
- **Interactive Components:** Custom floating cursor, immersive 3D tilt cards, and a developer-centric terminal aesthetic.

## 🛠️ Tech Stack
- **Frontend Framework:** React.js + Vite
- **Styling:** Tailwind CSS + Custom CSS modules
- **Animations:** Framer Motion, GSAP (GreenSock)
- **Icons:** React Icons
- **Deployment:** Vercel (Recommended)

## 🚀 Quick Start (Run Locally)

1. **Clone the repository**
   ```bash
   git clone https://github.com/ShanuPrajapati12005/<repo-name>.git
   cd <repo-name>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   *The application will start on `http://localhost:5173`*
